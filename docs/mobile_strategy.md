# Mobile UI/UX Strategy - AI Lotto Analyzer

## 1. UI 흐름 개선

### 상단 헤더 (Header)

- **문제**: 모바일에서 로고만 보여서 현재 페이지 맥락이 약함.
- **개선**: `Dashboard`, `History`, `Models`, `System` 등 현재 페이지 타이틀 명시.
- **추가**: 짧은 상태 배지(`Online`/`Offline`)를 추가하여 백엔드/ONNX 연결 상태 시각화.

### 하단 네비게이션 탭 (Bottom Tabs)

- **문제**: 아이콘+텍스트 구성은 좋으나 탭별 활성 상태 대비가 약함.
- **개선**: 활성 탭에 글래스 효과 배경(Fill) 추가 + 살짝 확대(Scale-up) 애니메이션 적용.

### 대시보드 CTA (Call to Action)

- **문제**: 메인 버튼인 "Start Analysis"가 모바일 화면 하단으로 밀려 접근성 저하.
- **개선**: 상단에 "빠른 분석" 버튼(Primary) 고정 배치 또는 플로팅 버튼 고려. 상단 버튼 클릭 시 결과 영역으로 부드러운 스크롤 유도.

### 결과 요약 카드 (Summary)

- **문제**: 애니메이션이 강조되지만 스크롤이 길어져 한눈에 결과 파악이 어려움.
- **개선**: `합계`, `AC`, `홀짝` 등 핵심 데이터를 한 줄로 보여주는 "결과 요약 카드"를 상단에 스티키(Sticky) 형태로 배치.

## 2. 분석 섹션 개선

### History 통계 탭 구조

- **문제**: 차트가 너무 많아 모바일에서 스크롤 피로도가 높음.
- **개선**: `요약 탭(핵심 차트 3개)`과 `상세 탭(모든 차트)`으로 이원화하여 정보 밀도 조절.

### 보너스/핫 & 콜드 넘버

- **문제**: 숫자만 나열되어 있어 변화를 알기 어려움.
- **개선**: "최근 회차 대비 출현 증감" 뱃지(`▲`, `▼`) 추가. 신뢰도를 보여주는 작은 게이지 바(Bar) 시각화.

### 설명 및 툴팁

- **문제**: 합계/AC/끝수 등에 대한 설명 텍스트가 화면을 많이 차지함.
- **개선**: 텍스트를 최소화하고 툴팁(Tooltip)이나 `ℹ️` 아이콘 팝오버로 대체하여 화면 밀도 개선.

## 3. 모바일 가독성 및 조작성

### 타이포그래피 (Typography)

- **문제**: 모델 카드 등의 텍스트가 모바일에서 작아 읽기 힘듦.
- **개선**: 1줄 요약만 우선 노출하고, 상세 내용은 '더보기' 형태로 펼침(Accordion) 처리.

### 카드 레이아웃 및 리듬감

- **문제**: 유사한 형태의 카드가 반복되어 단조롭고 구분이 안 됨.
- **개선**: 구역별로 배경색 농도를 조절하거나 미세한 구분선을 추가하여 시각적 리듬감 부여.

### 숫자 볼(Lotto Ball) 터치 경험

- **개선**: 최소 터치 영역 44px 이상 확보. 화면 크기에 관계없이 일정한 볼 크기 유지하여 정밀한 선택 지원.

## 4. 향후 분석 기능 확장 방향

1. **최근 10회 급변 트렌드**: 52회 장기 분석 외에 최근 10회차에서 급격히 자주 나오는 번호나 패턴을 별도 카드로 강조.
2. **개인화 패턴 비교**: 사용자가 직접 선택한 번호나 히스토리를 통계 데이터와 비교하는 "내 선택 패턴 vs 전체 통계" 차트.
3. **모델별 추천 사유 명시**: 각 AI 모델 카드 하단에 추천 이유(예: "Recent 30 Weighted") 1줄 표시로 신뢰도 확보.
